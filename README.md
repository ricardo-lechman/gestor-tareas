Es una aplicación de escritorio multiplataforma que funciona como una lista de tareas, notas y lista de compras:

📌 Crear, completar y eliminar tareas + guardar datos localmente.


Funcionalidades principales

Añadir tareas

Escribís en el input una tarea y la agregás a la lista con el botón Agregar.

Marcar como completada

Si hacés click sobre una tarea, se marca/desmarca como terminada.

Eliminar tareas

Cada tarea tiene un botón ❌ para borrarla.

Persistencia con localStorage

Si cerrás y volvés a abrir la aplicación, las tareas quedan guardadas en tu PC (no se pierden).

Maneja el ciclo de vida de la app (abrir, cerrar, etc.).
