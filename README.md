# 📋 Gestor Personal (Tareas, Notas y Compras)

## 🎯 Objetivo
Este proyecto es una pequeña aplicación hecha con **HTML, CSS, JavaScript y Electron**.  
La idea es tener un lugar sencillo donde pueda organizar **mis tareas, notas y listas de compras**, todo en una misma ventana.  
Lo hice como práctica para aprender a usar **Electron** y para mejorar en programación web.

---

## Funcionalidades principales

Añadir tareas
Escribís en el input una tarea y la agregás a la lista con el botón Agregar.
Marcar como completada
Si hacés click sobre una tarea, se marca/desmarca como terminada.
Eliminar tareas
Cada tarea tiene un botón ❌ para borrarla.

## ⚙️ Instalación
1. Clonar este repositorio:
   git clone https://github.com/tuusuario/tu-repo.git
   
2. Entrar a la carpeta:
   cd tu-repo
   
3. Instalar dependencias:
   npm install

4. Ejecutar la app:
   npm start
